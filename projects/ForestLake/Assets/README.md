# ForestLake assets

A mountain lake in a fir forest at golden hour, made to show the renderer: card fir
trees, alpha-cutout foliage with translucency, cascaded shadows and water that
reflects the shore.

`Models/` is not in git (about 240 MB). Build it:

```bash
python3 projects/ForestLake/Tools/fetch_assets.py                # Poly Haven downloads, once
blender -b --python projects/ForestLake/Tools/blender/build.py   # writes Assets/Models
python3 projects/ForestLake/Tools/generate_forest_lake_scene.py  # project file and scene
```

| Model | What it holds |
|---|---|
| `Terrain.gltf` | The lake basin, shores, hills and distant mountains: 130k faces on a grid that is dense at the camera and coarse at the horizon |
| `Forest.gltf` | 518 firs, instances of 12 meshes generated by `Tools/blender/firgen.py` from Poly Haven's `fir_tree_01` twig atlas and bark |
| `Props.gltf` | Mossy rocks, boulders, cliffs, stumps, roots and a fallen trunk |
| `Plants.gltf` | Ferns, grass and shrubs near the camera |

All source assets are from [Poly Haven](https://polyhaven.com), CC0. The scene is
about nine million triangles: it is a showcase, not a frame-rate target.
